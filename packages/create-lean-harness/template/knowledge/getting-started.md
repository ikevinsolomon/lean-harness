# Getting started with {{name}}

This folder is the assistant's knowledge base. Every Markdown file here is split into
sections the assistant can search with `search_knowledge`, so it answers from your
documents instead of guessing.

## What to put here
- Policies and procedures: refunds, escalations, approvals.
- How-to guides for your products and internal tools.
- Answers to the questions people ask most often.

## Tips
- One topic per file, with clear headings: each heading starts a searchable section.
- Keep facts current. The assistant reads these files when the server starts.
