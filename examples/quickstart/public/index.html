lean harness · quickstart

An agent you can drop into any page.

This demo is a small task-tracking domain: task tools, a clock, long-term memory and a searchable planning guide. Switch models from the menu at any time, even mid-conversation.

Embed the same chat anywhere with two lines:

<script type="module" src="https://your-server/lean-chat.js"></script>
<lean-chat endpoint="https://your-server"></lean-chat>

No API key yet? The Mock model works offline. Try a tool directly:

  • /add_task {"title": "Ship v0.1", "priority": "high"}
  • /list_tasks
  • /current_time {"timeZone": "Asia/Kolkata"}
