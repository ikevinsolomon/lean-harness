# Planning guide (example knowledge)

This file is sample content for the quickstart. Replace the files in this folder
with your own documents; the assistant searches them with `search_knowledge`.

## Priorities

- **High**: blocks someone else, or has a deadline this week.
- **Normal**: should happen this month.
- **Low**: nice to have; review every Friday and drop what no longer matters.

## Due dates

Give every high-priority task a due date. If a task has no date, ask for one
before adding it.

## Weekly review

Every Friday: close finished tasks, move unfinished high-priority tasks to
Monday, and pick the three most important tasks for next week.
